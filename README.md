# Голосовой процессор

Берёт звук с микрофона, убирает шум, меняет голос и отдаёт результат в **виртуальный микрофон**.
Этот микрофон потом выбирается в Discord, Zoom, Telegram, OBS, играх и т.д.

```
Микрофон → [шумоподавление → гейт → смена голоса] → виртуальный кабель → Discord/Zoom/игра
```

## Установка (Windows)

1. Установи **Python 3.10+** с python.org (поставь галочку «Add Python to PATH»).
2. Установи бесплатный виртуальный аудиокабель **VB-Cable**: https://vb-audio.com/Cable/ (после установки перезагрузи ПК).
3. В папке проекта выполни:
   ```
   pip install -r requirements.txt
   python voice_app.py
   ```
4. В приложении:
   - **Микрофон (вход)** — твой реальный микрофон;
   - **Виртуальный микрофон (выход)** — `CABLE Input` (выбирается автоматически, если VB-Cable установлен);
   - нажми **Запустить**.
5. В Discord/Zoom/игре в настройках микрофона выбери **`CABLE Output`**.

Хочешь слышать себя — выбери свои наушники в пункте «Слушать себя». Только в наушниках, иначе будет эхо.

## Как настроить шумоподавление

- Нажми **«Откалибровать шум»** и помолчи 1 секунду: приложение запомнит фоновый шум (вентилятор, гул).
- **Сила шумоподавления**: 1–2 для обычной комнаты, выше — для сильного шума (но голос станет «металлическим»).
- **Порог гейта**: подними, пока в паузах индикатор показывает «закрыт», а во время речи — «открыт».

## Получить .exe без Python (через GitHub)

1. Зарегистрируйся на github.com и создай новый репозиторий (**New repository**, любое имя, можно приватный).
2. На странице репозитория нажми **uploading an existing file** и перетащи туда **все файлы проекта вместе с папкой `.github`** (сами файлы, а не папку `VoiceProcessor`). Нажми **Commit changes**.
3. Открой вкладку **Actions**. Сборка запустится сама (если нет — выбери «Build Windows exe» → **Run workflow**). Займёт 3–5 минут.
4. Когда появится зелёная галочка, открой сборку и внизу в разделе **Artifacts** скачай `VoiceProcessor-windows`. В архиве лежит `VoiceProcessor.exe`.

Если папка `.github` не загрузилась: **Add file → Create new file**, в имени напиши `.github/workflows/build.yml` и вставь содержимое одноимённого файла из проекта.

## Собрать .exe на своём ПК

Запусти `build_exe.bat` → получишь `dist\VoiceProcessor.exe`, Python на другом ПК не нужен.

## Заметки

- Задержка около 30–50 мс. Режим «Низкий/Высокий» не сохраняет тембр (формант), поэтому слишком большие значения звучат «мультяшно».
- macOS / Linux: код работает, но виртуальный микрофон нужен свой — BlackHole (macOS) или `module-null-sink` в PulseAudio/PipeWire (Linux).
